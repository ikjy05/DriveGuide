# 길목 (DriveGuide)

지나는 길의 관광지와 드라이브 코스를 추천하고, 터치 한 번으로 내비 경유지에 넣어 주는 Pleos Connect 차량용 앱입니다.

## 기능

- **지역 추천**: 새 시·군·구에 들어서면 음성으로 알리고, 주변 관광지와 여행코스를 사진 카드로 보여 줍니다.
- **가는 길**: 내비 경로를 따라 최대 60km 앞까지 들를 곳을 미리 추천합니다.
- **내비 연동**: 경유지 추가, 목적지 안내, 여행코스 전체 경로 안내.
- **헤드업 알림**: 앱을 열지 않고 알림에서 바로 경유지를 추가하거나 저장합니다.
- **저장**: 나중에 갈 곳을 기기에 저장합니다.
- **차량 대응**: 주행 중 긴 글 숨김·음성 읽기, 분할 화면(1:1, 2:1, 1:2), 라이트·다크 모드.

## 실행

1. [공공데이터포털](https://www.data.go.kr/data/15101578/openapi.do)에서 "한국관광공사_국문 관광정보 서비스_GW"를 신청하고, **Decoding** 키를 `local.properties`에 넣습니다.
   ```
   TOUR_API_KEY=발급받은_디코딩_키
   ```
2. Pleos Connect 에뮬레이터를 띄우고 설치합니다(JDK 17 필요).
   ```bash
   ./gradlew installDebug
   ```
3. Virtual Console에서 주행을 시뮬레이션하면 추천이 갱신됩니다.

## 구조

- `navi/`: NaviHelper SDK 래퍼(위치, 경로, 경유지·코스 안내)
- `tour/`: TourAPI 클라이언트, 여행코스 캐시
- `route/`: 가는 길 지점 추정
- `notify/`: 헤드업 알림
- `saved/`: 저장 목록
- `ui/`: 카드, 상세 화면, 사진 보기
